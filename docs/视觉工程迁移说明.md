# 两份工程的用途

`basic_framework_mc02-master (1)/basic_framework_mc02-master` 保留单轴自检、采集与离线分析。

`shaobing_gimbal-main/shaobing_gimbal-main` 用于相机指令控制、正弦调试和折叠。本次只把相机相关功能移到这份工程，没有加入自检状态机。编译、烧录时先确认打开的是哪份工程。

## 接线与数据

- 相机接口：开发板 Type-C 的 USB CDC 虚拟串口。上位机连接后会出现一个虚拟 COM 口，不需要设置 UART 波特率；上位机直接发送 62 字节相机帧。
- 调试串口：UART10，921600、8N1；PE2 为 RX，PE3 为 TX。VOFA 选 JustFloat，输出当前选择电机的目标角度、实际角度，单位为度。
- DJI 6020 接 FDCAN1，ID 3；三台达妙接 FDCAN2，pitch ID 1、roll ID 6、大 yaw ID 3。保留当前驱动中的主站 ID 和总线参数。

相机发 62 字节小端二进制帧，帧头 `A5 00`。CRC 覆盖前 60 字节，初值 `FFFF`，右移多项式 `8408`，不作最终异或，低字节先发。`yaw`、`pitch`、`bigYaw` 都按度解释；`mode` 只保存，不用作使能条件。其余字段保留解析，尚未参与控制。

## 控制流程

1. 开机等待电机位置反馈。roll 不在展开位置时，先保持另外三轴的当前位置，再以 50°/s 展开 roll。
2. roll 到位并稳定 200 ms 后，在 INS 任务内采集 100 次加速度重新初始化姿态。达妙切模式后有 60 ms 的使能等待，开机流程另留 150 ms 等首帧反馈。
3. 在展开后的姿态参考下记录三个关节的编码器坐标，供视觉角度换算；不覆盖机械零点。记录参考之前收到的相机帧不执行。
4. 新有效帧覆盖三个独立目标：`yaw` 给小 yaw，`bigYaw` 给大 yaw，`pitch` 给 pitch，不累加，也不让两个 yaw 一起追同一个 IMU yaw。视觉接管后清除正弦和回零轨迹。
5. pitch 输入范围 ±70°，两个 yaw 输入范围 ±90°；整帧中任何一轴越界就丢弃。100 ms 没有可执行的新帧时，三轴停止更新并保持当前位置。
6. 折叠、折叠完成和展开过程中不执行视觉目标，带 ID 的旧调试指令也不能绕过互锁。

这里的执行方式是“展开后建立固定参考，再换算各关节目标”。编码器负责各关节的位置闭环；没有把末端 IMU 的实时 yaw 同时接到两个 yaw 位置环。IMU 重初始化仍以重力方向初始化 pitch/roll，并不是把任意倾斜姿态的三个欧拉角都写成 0。若后续需要相对初始姿态的实时四元数闭环或底盘转动补偿，需要另行明确视觉与下位机的分工；本次迁移没有新增该功能。

## 调试命令

所有命令以英文分号结束。

| 命令 | 用途 |
| --- | --- |
| `pitch;` / `yaw1;` / `yaw2;` / `roll;` | 选择曲线与调参对象；yaw1 是大 yaw，yaw2 是小 yaw |
| `akp,150;` | 调当前轴角度 Kp；达妙对应 MIT Kp |
| `skp,1;` | 调当前轴速度 Kp；达妙对应 MIT Kd |
| `p,5;` | 选中 `yaw2` 后将小 yaw 目标设为相对固定零点的 5°，并启用位置控制；只用于小 yaw 调试 |
| `e;` | 进入当前轴的本地正弦调试，同时屏蔽视觉接管 |
| `a,5;` / `f,0.2;` | 本地正弦幅值与频率，单位为度和 Hz |
| `s;` | 停止正弦或视觉运动，再按原逻辑缓慢回机械零点；持续收到相机帧也不会自动重新启动 |
| `aim;` | 结束上述屏蔽，允许随后到来的新相机帧接管 |
| `z;` | 三轴先回机械零点，再折叠 roll；期间保持另外三轴 |
| `u;` | 展开；开机展开因反馈问题中止后，也用此命令重试 |

上电默认允许视觉接管，无需先发 `e;`。本地正弦只用于调试，不能与视觉同时运行。VOFA 曲线沿用原来的机械软件零点坐标；相机目标则以本次建立的姿态参考为中心，二者存在启动位置偏移时显示数值会不同。

小 yaw 调 PID 时先完成上方手动零点标定，再发送 `yaw2;`、`p,5;` 或 `p,-5;` 观察定位响应；`akp,<值>;`、`skp,<值>;` 分别只修改角度环和速度环比例增益。每次只调整一个参数，`s;` 停止当前运动并缓慢回零。此流程不需要启动正弦波。

## 代码入口

- `application/robot.c`：`GimbalInit()` 后调用 `CameraAimInitUsb()`。
- `USB_DEVICE/App/usbd_cdc_if.c`：USB CDC 收到数据后调用 `CameraAimUsbReceive()`；该函数再交给相机帧解析器。
- `modules/master_machine/camera_aim.c`：按连续 USB 字节流找帧头、处理拆包/粘包、校验 CRC、解出字段。
- `application/gimbal/gimbal.c`：开机展开、参考建立、视觉目标、超时和折叠互锁。
- `application/gimbal/dm_control.c`：相对角度换算成 MIT 位置指令，沿用当前参数和反馈映射。
- `modules/imu/ins_task.c`：在 INS 任务内执行姿态重初始化，复用滤波器内存。

两份工程均沿用原 MSYS2 make 与 ARM GCC 工具链。软件编译和桌面测试不能代替上机验证；首次对接先发三轴 0°，再单轴发小角度，核对方向、目标覆盖、断流保持与折叠互锁。
